The Architecture

Behind the AI Verdict

ReturnGuard uses a multi-stage deterministic pipeline. By combining the rigid math of visual embeddings with the reasoning of language models, it eliminates false rejections.

Step 01

Establish Ground Truth

At the fulfillment center, warehouse staff capture 3 photos (front, back, side) of the item. Backgrounds are stripped, and a DINOv2 neural embedding is stored as the absolute reference point.

Step 02

Neural Similarity Scoring

When the return arrives, it is photographed again. The system compares the new embeddings against the ground truth. If the structural similarity exceeds 60%, the return is instantly accepted.

Step 03

Parallel VLM Agents

For ambiguous items scoring below 60%, three independent Vision-Language Models are spawned. They act as forensic inspectors, analyzing each angle for wear, missing tags, or counterfeit material differences.

Step 04

The Final Judge

A coordinator LLM reads the reports from all three agents. If all agents identify clear fraud, the return is rejected. If there is any disagreement, it routes to a human, guaranteeing zero false rejections.
